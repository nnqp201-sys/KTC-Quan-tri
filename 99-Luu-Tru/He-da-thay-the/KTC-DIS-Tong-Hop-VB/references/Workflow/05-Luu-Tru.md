# 05-Luu-Tru

## Purpose
Define the storage workflow after a document has been issued.

## Steps
1. Save the final version.
2. Store the related references and attachments.
3. Assign metadata for future retrieval.
4. Link the document to the correct folder or category.
5. Confirm archive completeness.

## Outputs
- Archived file set
- Metadata entry
- Retrieval reference
