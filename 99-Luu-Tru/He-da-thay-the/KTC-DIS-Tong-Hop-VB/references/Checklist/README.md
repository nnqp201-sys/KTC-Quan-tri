# 08-Checklist

This folder contains review checklists used before a document is approved or issued.

## Core checklist groups
- `01-The-Thuc`
- `02-Noi-Dung`
- `03-Phap-Ly`
- `04-Ngon-Ngu`
- `05-Hinh-Thuc`
- `06-Metadata`
- `07-Theo-Loai-Van-Ban` (checklist cụ thể theo từng loại văn bản: Quyết định, Kế hoạch, Báo cáo, Thông báo, Tờ trình, Công văn, Biên bản)

## Purpose
Use the checklist library to verify document readiness quickly and consistently.
