# 05-Skill-Phan-Tich-Yeu-Cau_v2 (chuẩn "5 thành phần")

## Chuẩn 5 thành phần
1. Mục tiêu — kết quả cụ thể cần đạt.
2. Dữ liệu đầu vào — đối chiếu Nguyên tắc 1, kho 01-04.
3. Quy trình — rà soát chính thức (897) / rà soát nhanh / so sánh / chuẩn hóa — chọn đúng.
4. Tiêu chí nghiệm thu — đúng thể thức, đúng căn cứ, đúng văn phong Trường.
5. Người kiểm tra — ai rà lại kết quả trước khi dùng chính thức.

## Quy tắc
Thiếu Mục tiêu/Dữ liệu đầu vào quá nhiều → phải hỏi lại, không tự đoán.
